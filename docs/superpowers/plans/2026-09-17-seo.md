# Content SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist and render per-article and per-product SEO metadata with safe fallbacks.

**Architecture:** Reuse Product's existing `metaTitle` and `metaDesc`; add the missing localized SEO fields to Product and a complete SEO shape to Article. Existing admin CRUD and the storefront GraphQL proxy carry the data, and Next metadata consumes it.

**Tech Stack:** PostgreSQL migrations, TypeORM, NestJS/class-validator, Next.js Metadata API, gql.tada.

**Spec:** `docs/superpowers/specs/2026-09-17-content-cms-design.md`

## Global Constraints

- Add a forward migration after `047_*`; never edit historic migrations.
- Localized text is JSONB with `{}` defaults; no SEO module or new dependency.
- Preserve Product's `metaTitle`/`metaDesc` fields and existing fallback behavior.
- Run focused Jest tests and backend/storefront/admin checks before completion.

Set `title`, `description`, `keywords`, Open Graph title/description/images, and Twitter title/description/images from the selected SEO values. Preserve existing canonical and locale-alternate URLs.
